# Crest permissions

GIBSON is an unofficial fan project with no affiliation to the NIFL or any club. Club crests
are registered trademarks owned by the clubs. Every real crest shipped in `public/crests/`
is used **by explicit permission of that club**, on the terms recorded below.

**A crest may not be added to `public/crests/` until its permission is recorded here.**
`scripts/verify.js` fails if a crest file exists without an entry, so this file cannot
quietly fall out of step with what the site actually serves.

Clubs with no entry below fall back to GIBSON's own generated shield, which uses only the
club's colours and three-letter code — no trademark is reproduced.

## If permission is withdrawn

Delete the file from `public/crests/` and move the club's entry here to a "Withdrawn"
section with the date. The generated shield takes over immediately — no code change and no
redeploy of anything else is required.
